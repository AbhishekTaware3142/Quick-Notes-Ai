# QuickNotes AI

A React markdown note-taking app with local AI-style actions: summarize, rewrite tone, auto-tag, and continue writing.

## Features
- Create, edit, and save notes in the browser
- Local note summarization
- Tone-based rewrite (Formal / Casual / Professional)
- Auto tag suggestions
- Continue writing unfinished notes
- No external API key required

## Setup

```powershell
cd "c:\git code\quicknotes-ai\frontend"
npm install
npm run dev
```

## Open the app

- Frontend: `http://localhost:5173`

## Notes
- This version runs entirely in the browser and does not require a Claude API key.
- The backend folder is not required for local mode.
